# Northstar Product Images

Upload the Northstar Retail Co product images into this folder.

## Important

The product names are printed on the images themselves, so the filenames do not need to contain the product names.

For the best results, keep the original image files from:

`The-Northstar-Group-Project/public/images/`

Do not rename or compress the images unless necessary. The chatbot will use this directory as its self-contained product-image library.

## Expected structure

```text
public/
└── images/
    ├── product-image-01.jpg
    ├── product-image-02.jpg
    ├── ...
    └── README.md
```

After uploading the images, the frontend can be mapped to the corresponding catalog records in `data/product_catalog.json`.
